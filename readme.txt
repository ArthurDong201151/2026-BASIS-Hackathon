Crime Test is a satirical personality test game that calculates a user's likelihood of “criminal escalation” based on their everyday habits. The app uses an interactive 0–4 slider scale to evaluate how users react to common and low stakes scenario like hoarding free store samples, permanently "borrowing" school pens, or sharing streaming passwords. By tallying the scores across ten dynamic questions, the underlying algorithm categorizes the player into one of four custom behavioral archetypes, ranging from a perfectly compliant model citizen to an absolute public menace, making for an entertaining and interactive project.
